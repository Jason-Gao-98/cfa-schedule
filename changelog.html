v1.7.0 2026-10-31 最新
  • 豆瓣关联：每部影片自动关联豆瓣电影条目。构建期用脚本把每部影片的豆瓣 ID / 评分 / 海报固化为站内静态映射表（douban-map.js），前端查表展示、零额外请求，数据量再大也不卡。
  • 海报默认带出豆瓣海报：影片海报优先展示该片豆瓣条目对应的海报；点击海报直接在新页签打开该影片的豆瓣详情页。
  • 豆瓣评分：每场排片时间行新增绿色「豆瓣 X.X」徽章（悬浮可见），无评分或未收录时不显示。
  • 按「片名 + 年份」匹配豆瓣条目，同名不同年（如《四渡赤水》1983 与《四渡》2026、《茜茜公主》三部曲）不会串；豆瓣海报加载失败时自动回退资料馆海报。
  • 未命中精确豆瓣条目的影片，点击海报/占位退到豆瓣搜索页，保证每部影片都能一键跳转豆瓣。
  • 场次票价：排片时间行新增橙色「XX 元」徽章，票价来自江南分馆官方排片表（接口不返回票价，构建期人工核对整理为静态表 prices.js，前端查表零请求）；每日自动存档同步写入 price 字段，历史场次也能回查票价。
  • 精简：移除排片卡片上的「已放映」标识（灰色标识信息量低、视觉冗余；存档补档逻辑不变）。
  • 海报修复：豆瓣海报此前直连豆瓣 CDN，被浏览器 ORB 安全机制拦截后回退成了资料馆剧照（局部画面）甚至裂图；现改为构建期把 138 张豆瓣主海报下载到本站 assets/posters/，页面直接加载本地图片，彻底免疫跨域拦截；加载失败按「豆瓣 CDN → 资料馆海报 → 占位符」逐级回退。海报改为按原始 2:3 比例完整展示（去掉固定高度裁切），不再截掉上下部分。
v1.6.0 2026-10-31
  • 排片历史存档：资料馆接口会把已放映的场次逐渐剔除，历史排片原本无从查起。现由 GitHub Actions 每天自动把「当月 + 下月」的完整排片（片名、时间、影厅、年份、片长、制式、公众号补充场次等，不含上座率等动态数据）保存到仓库 archive/ 目录。
  • 自动补全已放映场次：「按月查看」时，接口不再返回的已放映场次会用站内存档补全，并标注灰色「已放映」标识；已放映场次不再提供「上座率」入口，其余（影片详情、搜索、统计、日历计数）保持一致。
  • 接口完全无数据的历史月份，只要存档里有记录就能整月查看，并提示「以下为站内每日自动保存的历史存档」。
  • 存档内容无变化时不产生提交，仓库历史保持干净；也支持在 Actions 页面手动触发并指定月份。
  • 修复：「全部排片」模式（默认视图）此前未合并存档，已放映场次不显示「已放映」标识，现已与「按月查看」行为一致；同时只向当月/下月请求存档文件，避免无意义的 404 请求。
v1.5.0 2026-10-31
  • 上座率按需查询：不再打开页面就批量拉取所有影片的上座率，改为每条排片右侧一个「上座率」按钮，点击后才查询该场次，数据量大也不卡。
  • 影厅座位图弹窗：点击按钮弹出座位图，直接标出每个座位的状态——已售（红）、可售（蓝）、不可用（灰）、状态未知（浅灰），顶部显示座位数 / 已售 / 余票 / 上座率汇总。
  • 按各厅实际座位排布：每排按该厅真实座位数渲染，裁去接口两侧占位留白，中间占位显示为过道断位，整排无座位的排渲染为过道虚线；座位内显示排内序号，悬停可见「X排N座」。
  • 修复：识别选座接口的 statu 字段（1 = 已售、0 = 可售、-1 = 非座位占位），已售座位此前全部被渲染成灰色的问题已解决。
  • 弹窗自适应：座位弹窗宽度贴合座位图本身——小厅小窗、大厅大窗（上限 1180px / 屏宽），整排超出可视范围时按比例整体缩放，窗口变化时实时重算；遮罩始终铺满全屏、弹窗固定水平居中。
  • 查询过的场次缓存为列表徽章（上座 XX%），未查询过的不显示，避免重复请求。
  • 「全部排片」模式下隐藏月份左右切换箭头；统计里的「部影片」改为按片名去重，不再与场次数相同。
  • 补充淘票票渠道场次：江南分馆部分场次（如 2026 修复影展的 1 号厅 / 2 号厅档期）官网放映日历与资料馆 APP 尚未上架，但淘票票可正常购票。现把江南分馆公众号「2026年11月学术放映观影日历」排片表中接口缺失的场次手工补入，与接口数据合并展示，并以「公众号 · 淘票票」徽章标注来源；这些场次没有影片详情页与上座率数据，官网日后上架时会自动去重。
