v1.8.1 2026-11-04 最新
  • 上座率查询更稳健：影片检索增加回退——原名查不到时依次尝试「去括号 / 去副标题」版本与英文原名；开演时间允许 ±3 分钟误差，但只在同影院、同影厅号且唯一命中时采用，避免串场。
  • 登录失效不再误报：此前 token 过期时票务检索会静默返回空列表，被误报成「未匹配到该场次」。现在查不到场次时会先核对登录态，失效则直接提示重新登录。
  • 提示更准确：区分「票务系统影片库里没有该片」与「影片在票务系统但本场次无排期」。经查证，「活动 / 映后交流」类专场（如 11/7 12:30《上海女儿》）即使已在 APP 开售并可选座，也不会在影片库中单独建条目，本站在技术上无法定位其座位图，此时会明确提示到 APP 查看，不再误报为「尚未开售」。
v1.8.0 2026-11-03
  • 海报修复：豆瓣海报此前直连豆瓣 CDN，被浏览器 ORB 安全机制拦截后回退成了资料馆剧照（局部画面）甚至裂图；现改为构建期把 138 张豆瓣主海报下载到本站 assets/posters/，页面直接加载本地图片，彻底免疫跨域拦截；加载失败按「本地 → 豆瓣 CDN → 资料馆海报 → 占位符」多级回退，不再出现裂图。海报按原始 2:3 比例完整展示（去掉固定高度裁切），不再截掉上下部分。
  • 高分标注：豆瓣评分 ≥ 8.5（含等于）的影片，评分徽章升级为金橙渐变样式（★ +「豆瓣 X.X」），与普通绿色徽章同一套尺寸与圆角；判断集中在评分渲染函数一处，排片列表与存档/历史视图统一生效，无评分影片保持不显示。
  • 影厅水印：排片卡片中部空白带新增大号厅号水印，以整张卡片为基准固定列对齐——所有卡片数字位于同一水平基准线与同一条右缘竖线（等宽数字 + 固定行盒），不随内容高度抖动；右侧与按钮列保持固定安全距，零遮挡。按厅号给克制色相（1 号浅蓝 / 2 号浅青 / 3 号浅琥珀 / 其余中性），约 13% 不透明度，压在文字下层。
  • 时间行不再显示「X号厅」小标签，厅号改由屏幕阅读器可读的隐藏文本承载，窄屏自动隐藏水印。
  • 首页默认展示当天排片：打开站点即自动选中「今天」并直接渲染当天场次，无需再点日期；可前后翻日或用「回到今天」，也可用 ?date=YYYY-MM-DD 链接分享具体某天。日期按北京时间（UTC+8）计算，避免跨日错位。若今天已无场次（放映结束/未排片），自动跳到最近一个有排片的前向日期并给出轻量提示；接口异常时以每日存档兜底并提示来源。首屏加载期间显示骨架屏，不再出现空列表闪跳。
  • 「全部排片 / 按月查看」切换后同样自动定位到今天所在的分组，而不是停在列表顶部；今天那一组带「今天」标记与高亮描边，便于一眼确认位置。当天无场次则定位到最近的前向日期并提示一条轻提示，全部无排片时停在顶部；滚动会按实际吸顶头部高度留出偏移，并尊重系统「减少动态效果」设置。每次切换只定位一次，用户手动滚动不会被打断。
  • 页头图标：左上角图标由自制同心圆标更换为中国电影资料馆的官方红色方章标识——直接使用资料馆官网页头原图（2025042309402671900.png）中的红色方章部分，仅做必要的裁紧裁切（去掉方章外留白、保留 1–2px 抗锯齿余量）后下载到本站 assets/logo-cfa-*.png，不重绘、不调色、不直连外链：无边框、无白底、无阴影，红色方章贴边铺满、按官方原始比例展示；同时用同一份裁切结果补齐 favicon 与 apple-touch-icon（32 / 96 / 180 / 512）。
  • 场次票价（重做数据管线）：v1.7 预留的价签此前没有真实数据（票价表是空的）。现改为可复核的三段式管线：① 票价只从有出处的来源逐场登记到台账 scripts/price-ledger.json（含「来源 + 核对日期」，拿不到就不登记，绝不猜价）；② 由 node scripts/build-prices.mjs 校验后自动生成 prices.js（键为「日期|开场时间|影院|影厅|片名」，逐级回退到「日期|影厅|片名」「日期|片名」，值为单价或 [最低, 最高]，同场多档价才用区间）；③ 每日同步把票价写进 archive/YYYY-MM.json（price / priceMax / priceNote）。排片卡片右下角固定一枚醒目价签（深红实底白字、数字 19px，与绿色评分徽章、金橙高分徽章明确区分）：单一场价显示「¥40」，同场多档价显示「¥30–60」；价签排在右侧操作列底部，避开影厅水印与「上座率 / 影片详情」按钮，窄屏时右对齐到按钮整行末尾；历史/全部/按月视图同一套渲染；未知票价的场次不显示价签（不写「待定」占位，避免每张卡片都挂一个空标签）。每日存档的票价合并规则是只增不减：新抓到的价覆盖旧价（调价以最新为准）、本次没抓到价则沿用存档里的旧价、台账后补的票价可回填历史记录，Actions 日志每天打印覆盖率（有价/总场次、unknown 数）。2026 年 11 月已按公众号月度排片表长图逐场转录补齐：江南分馆 105 场、小西天 87 场、百子湾 35 场，共 227 场全部有价（价位 10–120 元），来源与原图存档见 scripts/sources/2026-11-jiangnan/ 与 scripts/sources/2026-11-beijing/；12 月场次在公众号发布新月历前暂无票价（显示为 unknown，不显示价签）。

  • 精简：移除排片卡片上的「已放映」标识（灰色标识信息量低、视觉冗余；存档补档逻辑不变）。
v1.6.0 2026-10-31
  • 排片历史存档：资料馆接口会把已放映的场次逐渐剔除，历史排片原本无从查起。现由 GitHub Actions 每天自动把「当月 + 下月」的完整排片（片名、时间、影厅、年份、片长、制式、公众号补充场次等，不含上座率等动态数据）保存到仓库 archive/ 目录。
  • 自动补全已放映场次：「按月查看」时，接口不再返回的已放映场次会用站内存档补全，并标注灰色「已放映」标识；已放映场次不再提供「上座率」入口，其余（影片详情、搜索、统计、日历计数）保持一致。
  • 接口完全无数据的历史月份，只要存档里有记录就能整月查看，并提示「以下为站内每日自动保存的历史存档」。
  • 存档内容无变化时不产生提交，仓库历史保持干净；也支持在 Actions 页面手动触发并指定月份。
  • 修复：「全部排片」模式（默认视图）此前未合并存档，已放映场次不显示「已放映」标识，现已与「按月查看」行为一致；同时只向当月/下月请求存档文件，避免无意义的 404 请求。

  • 「全部排片」模式下隐藏月份左右切换箭头；统计里的「部影片」改为按片名去重，不再与场次数相同。
