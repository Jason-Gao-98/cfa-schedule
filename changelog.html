v1.9.14 2026-11-07 最新
  • 本地排片问答：新增左下角「问排片」入口，打开后可中文提问。所有回答由站内排片数据（当前视图、archive/YYYY-MM.json 存档、prices.js、extra-schedule.js、events-2026-11.js）按规则推导，不联网、不调用大模型、不需要 API Key。
  • 能答什么：某天 / 明天 / 后天 / 周末 / 具体日期有什么；某影院（江南分馆、小西天、百子湾）或某影厅（如「3号厅」）；某部片的全部场次（支持模糊、别名与副标题，找不到时给出最相近候选片名）；时间段（晚上 7 点后、下午、10–12 点）；制式（4K / IMAX / 3D 等）；映后交流等活动（来自活动数据与补充场次备注）；统计（场次数、影片数、票价区间、最便宜 / 最贵）；以上条件可叠加。
  • 不能答什么：不编造场次、时间、厅号或票价；算不出来会明确说「没查到」并给出可换的说法；上座率不查、不猜，只提示点场次卡片上的「上座率」按钮登录查看；不预测未来排片，不回答与排片无关的问题。
  • 按需加载：只加载问题涉及的月份与日期，复用现有接口、存档合并与补充场次逻辑；已放映日期只信站内存档，今天及以后才拉接口明细，不会为了问答把全站数据一次性拉满。更远于「当月 + 下月」的月份不请求存档。
  • 交互与无障碍：回答按日期分组、每场一行（时间 / 片名 / 影院·厅号 / 票价），点任意一行可切到该日主列表并高亮对应场次；Enter 发送、Esc 关闭并归还焦点、焦点样式可见；输入框有 label，结果区 aria-live。对话历史仅存 sessionStorage（最多 8 轮），关掉页面即清空，不写 localStorage。
  • 布局：入口固定在左下角，避开右下角的「观影计划」按钮与日期小日历；桌面面板左下浮动，移动端（≤760px）改为底部整宽面板，并在打开时临时隐藏「观影计划」与日期小日历，避免叠层与遮挡。
  • 页头返回首页：点击页头红色方章或站名回到默认首页——当日视图、今天、清除 ?date= 等查询参数及搜索与影院筛选，并滚动到顶部；使用 <a href="./">，支持键盘 Enter、可见焦点与悬停反馈，图标尺寸与页头布局不变。
  • 更新日志页返回首页：更新日志页页头的方章与站名同样改为返回站点首页的链接（./），语义、键盘 Enter、焦点样式与悬停反馈同首页；页头「返回查询页」与页脚「返回排片查询」链接一并核对可用。1280 与 375 下页头布局不变。
